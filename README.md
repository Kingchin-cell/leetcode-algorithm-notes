## 使用方法

### 1. 环境准备

力扣支持 C++17，本地测试推荐：

```bash
g++ -std=c++17 main.cpp -o main
```

刷题时只需填写力扣给的 `class Solution` 函数体，**不用写 `main` 和 `#include`**（力扣会自动补）。

### 2. 按单元推进

每个单元按「看模板 → 做题 → 二刷错题」三步走。做题前先看 `算法教学.md` 对应章节。

### 3. 记录模板

每做完一道题，在题单的「考点」列旁边补一句自己的理解，形成个人模板库。

## 学习方法

1. **15 分钟卡点就看题解**：看完关掉题解**默写**一遍，写不出来再看。
2. **先画图再写代码**：链表题不画图必错。
3. **二刷只看错题**：做完 3 天后重写，一周内两次通关才算会。
4. **每道题记一句「这题属于哪个模板」**：积累 20 条后，看新题能条件反射。
